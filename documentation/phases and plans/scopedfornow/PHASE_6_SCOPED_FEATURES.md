# PHASE 6 SCOPED FEATURES
## Final Feature Decisions for Implementation

### ✅ **INCLUDED FEATURES**

1. **Equipment Slot Upgrades**
   - Start with 7 base slots, unlock additional slots through progression
   - Include ring2, amulet, accessory2 as unlockable slots

2. **Inventory Size Upgrades** 
   - Start with base inventory size, allow expansion through progression
   - Implement upgrade system for inventory slots

3. **Basic Vendor/Economy System Framework**
   - Implement basic framework for vendor system
   - Foundation for Phase 7 hub world integration
   - Simple buy/sell structure without complex pricing

### 🚫 **EXCLUDED/DEFERRED FEATURES**

1. **Multiple Currency Types**
   - **Decision**: Gold only for now
   - **Reason**: Simplify initial implementation
   - **Future**: Add elemental essences in Phase 7

2. **Set Item System**
   - **Decision**: Remove from Phase 6 scope
   - **Future**: Implement in later phase when item variety is established

3. **Advanced Item Generation**
   - **Decision**: Keep item generation simple for Phase 6
   - **Future**: Add complex affix pools and biome scaling later

4. **Detailed Stat Comparison UI**
   - **Decision**: Basic tooltips only for Phase 6
   - **Future**: Enhanced comparison UI in polish phases

### 📋 **IMPLEMENTATION NOTES**

- Focus on solid foundation that supports future enhancements
- Prioritize functionality over complexity
- Ensure architecture can accommodate deferred features
- Framework approach for vendor system prepares for Phase 7
